# ✨ Bankist - Interactive Banking Website

## 📌 Overview
**Bankist** is a modern and interactive banking website built to showcase **smooth animations, scrolling effects, and JavaScript-driven UI interactions**. It enhances user experience with dynamic elements while demonstrating fundamental web development concepts.

## 🚀 Features
- 🎢 **Smooth Scrolling:** Seamless navigation between sections.
- 🎭 **Section Revealing Animations:** Sections fade in as you scroll.
- 🔢 **Number Counter Animation:** Engaging counters for financial statistics.
- 🏦 **Tabbed Component:** Switch between different banking features dynamically.
- 🔄 **Lazy Loading Images:** Enhances performance by loading images only when needed.
- 📜 **Sticky Navigation:** Navigation bar sticks to the top when scrolling.
- 🏆 **Modal Window:** Pop-up modal for interactive user engagement.
- 🎨 **Sleek UI:** Designed with CSS transitions and JavaScript event handling.

## 🛠️ Tech Stack
- **JavaScript (ES6+)** - Core interactivity and animations.
- **CSS & HTML** - Styling and page structure.
- **Intersection Observer API** - Efficient scroll-based effects.
- **Event Delegation** - Optimized event handling for better performance.
